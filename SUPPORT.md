# Support

## Questions and usage help

For installation questions, model-usage questions or requests for clarification,
open a GitHub issue at:

https://github.com/PortoSpaceTeamNI/NoZZoMe/issues

Please include the operating system, Python version, NoZZoMe version, the command or
input case used, and the complete error message or exported summary.

## Bug reports

Before reporting a bug, check the existing issues and confirm that the problem is
reproducible from a clean environment. A useful report contains a minimal input case,
the expected behaviour and the observed behaviour.

## Engineering scope

NoZZoMe is a reduced-order preliminary-design and research tool. Its results are not
qualification evidence and do not replace mesh-refined CFD, structural/thermal
analysis, manufacturing review or experimental validation.
